# Customer Churn Analysis Dashboard

## Project Overview
The Customer Churn Analysis Dashboard is an interactive Power BI project designed to analyze customer retention and churn patterns. It helps identify customer behavior and explore factors that may contribute to customer churn.

## Objectives
- Analyze customer churn and retention rates.
- Explore customer demographics and service preferences.
- Compare churn across contract types.
- Examine monthly charges and customer tenure.
- Provide an interactive dashboard for data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and calculations
- Data Visualization and Exploratory Data Analysis

## Dashboard Features
- KPI cards for retention rate, churn rate, customer count, and tenure.
- Customer churn analysis by gender.
- Churn comparison across contract types.
- Monthly charges distribution.
- Customer tenure analysis.
- Interactive slicers for senior citizen status, internet service, and gender.
